PEAK / AUTONOMOUS PRODUCT UI

一套可切换、可验证、拒绝 Obsidian 样式侵入的设计系统。

这里定义颜色、字体、密度、圆角、层级、motion 与宿主边界；Theme Lab 用固定试件判断整体气质，UI Inventory 用真实录屏帧记录产品原貌。

调试 Theme 用标准试件换肤 看真实 UI Inventory

设计约束，不是样式清单

先固定职责和边界，再决定某个圆角或颜色。任何新界面都必须能映射到这些约束。

01 · Principles
01
Peak 视觉自主Peak 管理的 DOM 不继承 Obsidian 的颜色、字体、控件几何与状态样式。
.peak-design-root + .pktw-root
02
Semantic first组件只能消费 role token；Theme Pack 才能把 role 映射到具体色值。
--pk-surface / --pk-text-primary / --pk-accent
03
密度改变间距，不改变信息层级Compact 与 Comfortable 共用字号角色和组件结构，仅调整 row、padding 与 gap。
density ≠ scale transform
04
圆角表达层级控件用 md，容器用 lg，浮层用 xl；pill 只给短标签和互斥切换。
control md → panel lg → modal xl
05
阴影只表达 elevation文档内面板以 border 为主；popover、sidecar、modal 才逐级增加阴影。
base → card → popover → modal
06
Projection 不重新查询List / Tree / Graph 是同一 snapshot 的视图，切换不丢 selection、inspector 与 query。
snapshot → projection
07
主题感受与产品原貌分开Theme Lab 使用固定标准试件；真实页面外观进入 UI Inventory；交互只在 Obsidian 实机验收。
specimen / evidence / acceptance

Obsidian Host Boundary

“全部拒绝进入”需要三层防线：token 自主、继承中断、几何守卫；Portal 也必须带相同 ownership scope。

05 · Boundary
1
Token ownershipPeak 组件只能引用 --pk-*；Theme Pack 提供完整 Light / Dark semantic map。
禁止 var(--background-primary) 等宿主 token
2
Inheritance break根容器以 all: initial 重建 font、color、line-height、box sizing 与控件 reset。
.peak-design-root.pktw-root
3
Geometry defenseObsidian 对裸 button/input 的规则可能带高优先级；固定 hit target 必须显式声明 width / height / min / max / padding。
.peak-design-root .pk-btn { height: … !important }
4
Portal ownershipModal、popover、tooltip 不能挂到无 scope 的 document body 后继续假设 token 存在。
portal root carries both ownership classes
5
Automated defense阻止 Obsidian vars、裸 controls、inline theme hex 与缺少页面 scope 的回归。
docs/ui-system/validate.mjs + computed geometry QA

Theme Schema

Theme 是数据，不是另复制一份组件 CSS。导出后可以版本化、校验、预览与安全回退。

06 · Schema
可配置轴

pack 决定 neutral ramp；appearance 决定 light/dark；其余轴只映射各自职责。组件永远不知道当前 Theme 名称。

Fallback
无效值回落到 Peak Violet / Light / Comfortable / Balanced；缺失 accent 回落到 pack 默认值。
Codex image replacement
Theme Lab 固定展示四张 repo 图片。复制当前 Theme JSON 后，直接让 Codex 读取页面和 manifest、生成并覆盖固定 theme-concepts/current/*.jpg；不上传图片、不复制额外 Prompt，也不覆盖真实 evidence。
