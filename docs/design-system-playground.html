How should Peak isolate its design system?
SYNTHESIZED REPORT

Peak needs an autonomous theme boundary, not another layer of overrides.

12 sources verified6 min readUpdated now
核心不是把 Obsidian 的颜色盖过去，而是让 Peak 管理的 DOM 拥有完整 token、继承中断、Portal scope 与 geometry defense。

1. Establish ownership at the root

所有产品表面从同一 ownership class 进入，显式重建字体、颜色、line-height 与原生控件几何。Portal 需要复制相同 scope。

2. Theme is data

组件消费 semantic role；Theme Pack 只负责 role 到 value 的映射，因此切换颜色、Dark、radius 与 density 不需要复制组件 CSS。
