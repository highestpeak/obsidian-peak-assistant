05 · DOCUMENT COMPOSER

Composer

一个固定 Main、一个 Workspace、一个 Paper；场景切换只替换文档内容和上下文浮层，不再重新创建三套互相错位的纸张。

Peak Composer Visual Parity QA
Composer 的目标不是隐藏 Markdown，而是让 Markdown 在复杂对象面前也能保持可编辑、可理解、可回滚。
1. 知识库不是单一目录，而是多种结构叠加
知识库的结构，是根据想要存储的知识来设计的。碎片化思想、阅读摘录和灵感更适合网络结构；一门技术、一组课程或一本书的读书笔记更适合树状结构。
  • 网络结构：承接滑箱笔记、论文旁批、公众号想法和临时判断。
  • 树形结构：承接系统学习、技术专题、书籍章节和项目文档。
  • 跨库链接：保留来源、引用和迁移差异。
区分资料库、笔记和大脑，可以看成区分高速缓存、内存和硬盘。
同时保持 Base、Canvas、Excalidraw 等模块以原生块形式存在，确保 AI 能够准确解析其内容结构。
