Peak Composer Visual Parity QA
Composer 的目标不是隐藏 Markdown，而是让 Markdown 在复杂对象面前也能保持可编辑、可理解、可回滚。
4. 原地编辑必须能回到 Markdown 事务
真正危险的地方不是渲染，而是写回。段落、图片、表格、公式和 native embed 都要好编辑，但每一次修改都应该知道自己对应哪一段 Markdown。
  • 文本块写回普通 Markdown range。
  • 表格写回 pipe table，并保留对齐和排序。
  • 图片块保留 attachment 与原图。
5. AI 建议应该贴在块旁边，而不是把用户拉到远处聊天
对写作者来说，最自然的 AI 不是一个万能聊天框，而是当前块的候选动作。标题需要改名、段落需要扩写、列表需要补项，表格需要总结。
