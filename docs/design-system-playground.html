04 · IMAGE-TO-THEME BRIDGE

让 LLM 改图负责找方向，让 Theme Pack 负责落地

生成图是一张视觉假设，不是设计系统源码。最稳的输入是本页固定试件截图；最稳的输出是完整 Light / Dark token recipe。

固定工作流避免“改图很好看，产品无法实现”
  1. 1
    Capture

    截取固定试件，锁定内容、布局和状态。

  2. 2
    Generate

    要求模型只替换主题，不增删元素、不改变几何。

  3. 3
    Compare

    把生成图放到右侧，与实时 Theme Lab 并排比较。

  4. 4
    Tokenize

    提取语义色、radius、type、elevation 和 motion recipe。

  5. 5
    Validate

    补齐 Dark、Hover、Focus、Disabled、Error，再进入 Theme Pack。

Generated reference本地预览，不上传、不持久化
放入 LLM 生成的主题图PNG / JPG / WebP

图片只用于视觉对照。真正可应用的主题仍需导入 Theme JSON，并通过状态与对比度检查。

Keep every element, label, layout, spacing, component size and interaction state exactly unchanged. Replace only the visual theme: semantic colors, typography character, radius system, elevation and material treatment. Do not add or remove UI. Preserve information hierarchy and produce one coherent professional Peak product theme. Return a matching Light and Dark semantic token recipe alongside the image.
