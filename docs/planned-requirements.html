怎么用这份文档

Roadmap 只放标志性功能和关键节点；这里放已经被用户指出、但暂时不实现的 surface-level 需求。每条需求都要有入口、用户价值、链接到 spec 或低保真稿。

升级规则
小需求变成 implementation work 前，先补一份 spec 或 mock；如果它变成跨模块里程碑，再迁到 roadmap.html 的已决策待建。
