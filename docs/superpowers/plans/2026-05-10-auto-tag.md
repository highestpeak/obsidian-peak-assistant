> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Design red line:** Suggestion mode ONLY (Generation Effect). The panel already enforces this — never bypass it. Do not add any code path that writes tags without user confirmation.

- [ ] **Step 2: Create `TagSuggestionRepo`**

Create `src/core/storage/sqlite/repositories/TagSuggestionRepo.ts`:

```typescript
import { type Kysely } from 'kysely';
import type { Database as DbSchema } from '../ddl';
import { v4 as uuidv4 } from 'uuid';

export type SuggestionStatus = 'pending' | 'accepted' | 'rejected' | 'edited';

export interface TagSuggestionRow {
  id: string;
  doc_path: string;
  tag: string;
  category: string;
  confidence: number;
  sources: string;
  reason: string;
  is_existing: number;
  status: SuggestionStatus;
  edited_tag: string | null;
  created_at: number;
  resolved_at: number | null;
  batch_id: string | null;
}

export class TagSuggestionRepo {
  constructor(private readonly db: Kysely<DbSchema>) {}

  /** Insert a batch of suggestions for a document. Returns the batch_id. */
  async insertBatch(params: {
    docPath: string;
    batchId: string;
    suggestions: Array<{
      tag: string;
      category: string;
      confidence: number;
      sources: string[];
      reason: string;
      isExisting: boolean;
    }>;
  }): Promise<void> {
    const now = Date.now();
    await this.db
      .insertInto('tag_suggestion')
      .values(
        params.suggestions.map(s => ({
          id: uuidv4(),
          doc_path: params.docPath,
          tag: s.tag,
          category: s.category,
          confidence: s.confidence,
          sources: JSON.stringify(s.sources),
          reason: s.reason,
          is_existing: s.isExisting ? 1 : 0,
          status: 'pending',
          edited_tag: null,
          created_at: now,
          resolved_at: null,
          batch_id: params.batchId,
        })),
      )
      .onConflict(oc => oc.doNothing())
      .execute();
  }

  /** Resolve multiple suggestions at once (accept/reject/edit). */
  async resolveBatch(
    resolutions: Array<{ tag: string; docPath: string; batchId: string; status: SuggestionStatus; editedTag?: string }>,
  ): Promise<void> {
    const now = Date.now();
    for (const r of resolutions) {
      await this.db
        .updateTable('tag_suggestion')
        .set({ status: r.status, edited_tag: r.editedTag ?? null, resolved_at: now })
        .where('doc_path', '=', r.docPath)
        .where('tag', '=', r.tag)
        .where('batch_id', '=', r.batchId)
        .execute();
    }
  }

  /** Get suggestions for a document (latest batch). */
  async getLatestForDoc(docPath: string): Promise<TagSuggestionRow[]> {
    return this.db
      .selectFrom('tag_suggestion')
      .selectAll()
      .where('doc_path', '=', docPath)
      .orderBy('created_at', 'desc')
      .limit(20)
      .execute() as Promise<TagSuggestionRow[]>;
  }

  /** Get acceptance rate for a tag (across all docs). */
  async getAcceptanceRate(tag: string): Promise<number | null> {
    const rows = await this.db
      .selectFrom('tag_suggestion')
      .select('status')
      .where('tag', '=', tag)
      .where('status', '!=', 'pending')
      .execute();
    if (rows.length === 0) return null;
    const accepted = rows.filter(r => r.status === 'accepted' || r.status === 'edited').length;
    return accepted / rows.length;
  }
}
```

## Implementation Notes

### Schema alignment
`TagSuggestionEngine.RankedTagSuggestion` uses `category: 'topic' | 'keyword' | 'functional'` and `sources: Array<'content' | 'graph' | 'history'>`. The updated `tagSuggestionsSchema` must match both. The old `source` (singular) field in the schema is a bug from before the engine was written — Task 1 fixes it.

### `uuid` import
`TagSuggestionRepo` uses `uuidv4()`. The package `uuid` is already in `package.json` (used by chat repos). Import as: `import { v4 as uuidv4 } from 'uuid';`

### `AdaptiveConcurrencyPool` usage
```typescript
import { AdaptiveConcurrencyPool } from '@/core/utils/adaptive-concurrency';
const pool = new AdaptiveConcurrencyPool(3);
const results = await pool.mapAsync(files, async (file) => {
  const content = await app.vault.read(file);
  return { file, suggestions: await engine.suggestTags(file.path, content, file.basename) };
});
```

### DDL migration
The `chat.sqlite` DDL migrations run on init in `SqliteStoreManager`. The `CREATE TABLE IF NOT EXISTS` pattern means the migration is idempotent — safe to add at the next migration version.
