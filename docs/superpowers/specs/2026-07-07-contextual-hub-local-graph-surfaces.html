当前决定：File Atlas 拥有完整文档上下文

File Atlas 顶部 context row 展示 primary / candidate hubs 与 inbound / outgoing link counts；同一 surface 的 Graph subview 展示 local / two-hop neighborhood。旧 Document tab context strip 仅作为历史方案保留在下方，不应实现或恢复。

当前决定：Search 不再建设 Hub Drawer

Vault Search inspector 保留 connected / discovered / AI Graph 等搜索语义，并提供 Open in File Atlas。hub membership、source chain 与 local graph 由 File Atlas 继续展示，避免两套右侧面板在能力和状态上漂移。

为什么需要它

Vault 级 graph 回答“整个库的结构是什么”，但写作时用户经常只想知道“这篇文档在哪里”。这个问题应该出现在 Document tab 和 Search drawer 里，而不是要求用户跳到另一个全局图谱视图。

  • Document tab 是当前文档的 Copilot 面板，应该显示当前文档属于哪些 hub。
  • Search drawer 已经在展示 selected result 的 connected / discovered 信息，可以顺手展示 hub context。
  • 这些入口不新增命令，只是在已有面板里补上下文。

历史方案（已 superseded）：Document tab 局部图谱

在 current note 信息行和 review card 之间增加一个 context strip。它不替代 Review Article，也不自动改文档，只是让用户看见当前文档的 hub、出处链和局部图谱。
