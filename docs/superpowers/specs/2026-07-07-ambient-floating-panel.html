撤销决定

删除本分支新增的 AmbientFloatingPanelHost、drag / collapse / manual refresh chrome 与 floating CSS。Ambient runtime 的输出应进入 Composer Intelligence 的 Brief / Copilot lifecycle，并复用同一个 run identity、finding model 与 review handoff。

验收生产源码与 CSS 中不再存在 floating host；旧 Related Notes leaf 仅作为兼容 surface 保留，不代表新产品方向。

历史问题与被否决方案

Ambient Push 的价值不是“弹一个提示”，而是在用户写当前段落时，持续给出附近可能有用的笔记。右下角/状态栏短提示既解释不了推荐，也不方便点开；右侧 leaf 虽然稳定，但离当前写作焦点偏远，用户还不一定知道怎么打开。

产品判断 主形态应该是一个 Obsidian 窗口内的 floating panel：用户打开后它悬在编辑器上方，写作时保持可见；点 × 后消失；切到其它应用时不会变成系统级悬浮窗。
