最终页面架构

Vault Intelligence 是一个独立 View；内部动作不污染 Command Palette。

Overview

当前状态、最多 7 个 Continue work、What changed 与 Priority work。

不放完整 Graph

Vault map

Vault contents 合并结构与文件类型；Activity 先展示真实活动，再提供 AI 分析。

Contents + Activity

Work queue

有 Owner、有证据、有下一步、有退出条件的持久任务；行内展开。

不是 Finding 列表

Runs

Setup、Active、Completed、History / Compare；真实进度与真实结果。

完整维护运行

当前能力真相

仓库已有重要基础，但 V2 Mock 中大部分最终流程仍未接入生产。

当前可复用的能力

已有基础
  • Vault digest 与 AI Review 运行 / 历史
  • 19 个确定性 Vault Lint detectors
  • Search、Vectors、Summary、AI Tags enrichment
  • Community / Hub 数据与共享 Cytoscape Graph
  • Composer / Project / AI Graph / Peak Sheet Owner surfaces
  • Proposal、revision guard、receipt 的相邻模式

UI 与功能都没有的核心能力

必须新建
  • 统一 Scan orchestrator 与可恢复 checkpoint
  • 统一 CompletedRunResult 与 WorkItem canonical model
  • ActivityRecord、Heatmap、每日活动 List
  • AI event / theme 分析与 provenance
  • Pie → Community graph 同步投影
  • 动作后的局部 re-index / recheck / closure

关键设计结论

这些是整个 Session 反复讨论后已经收束的方向。

问题最终结论当前实现状态
首页放什么对象摘要、Continue work、变化、优先项；不放大 Graph 与 AI 长文仅 Mock
Files & Index不是独立顶层页；Files、Search、Summary、Tags 都属于 Vault contents / maintenance待接入
Graph共享 Cytoscape；Constellation、Flow →、↓、Orbit；点击 Community 原图展开底层已有
Activity默认原始记录 Heatmap；AI themes 按需生成并标 provenance核心缺失
Work item行内展开、动作专属 UI；不使用远距离右 Drawer 与通用 truth modal统一模型缺失
ScanRuns 独立 Setup → 真实 Active progress → 一页 Completed resultsMock 有，runtime 无
AI Review读取确定性事实，聚类、解释、比较、建议；不自动改文件，也不再是独立页面部分能力已有
Proposal用户文件逐项审阅；Peak-owned machine knowledge 可直接更新并记录 receipt待形成闭环
