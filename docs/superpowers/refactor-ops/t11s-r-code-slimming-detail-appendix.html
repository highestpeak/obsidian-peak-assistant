1. 怎么用这个附录

地图版回答“为什么和多少”

用来做 owner 决策：是否继续、下一波多大、目标是多少。

附录回答“具体在哪”

用来写 Claude prompt：哪些文件、哪些候选、哪些必须保护。

不要直接照单全删

每个候选都有不同处理方式：删除、合并、接线、隐藏、延后。

补救说明： 我之前把详细报告直接覆盖成可读版，这不符合“可读版和证据底稿分层”的要求。 这个附录就是把有用的旧调查内容重新归档。

8. 保护清单：这些不是删除候选

  • Usage Dashboard：用户明确需要。只能内部合并，不退役。
  • Chat 三栏 views：ChatView、ProjectListView、ConversationOutlineView 必须保留。
  • Vault X-Ray：默认保留，除非 owner 明确说退役。
  • Harness / Command Gateway 地基：先审计 overlap，不直接删。
  • SQLite schema / search ranking：必须有 fixture/snapshot 保护。
  • 当前正稿 docs：主架构手册、Ambient 专项、Command Gateway 专项、当前 owner reports 保留。
