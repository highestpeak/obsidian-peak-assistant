Peak Assistant — Getting Started

A lightweight walkthrough for new users. Read it once, get configured in five minutes, and skim the appearance section before you start writing in Chinese.

1. First Launch

Three steps from a fresh install to a working Peak Assistant. None of them touch your vault data — the Setup Wizard only writes to HarnessSettings, your provider bindings.

1 Enable the plugin Settings → Community plugins → toggle Peak Assistant on.
2 Open the command palette Cmd + P (macOS) or Ctrl + P (Windows / Linux).
3 Run the Setup Wizard Search "Peak Assistant: Setup Wizard" and press Enter. The wizard walks you through provider setup and model recommendations.
Re-running the wizard is safe. The same command opens in re-run mode when bindings already exist. It will not wipe your previous configuration — only let you adjust it.

2. Setup Wizard Flow

The wizard has six visible steps. Two more steps (edit-recommendation and redo-input) appear only as detours from the review screen.

# Step What it does
1 Welcome Introduces Peak Assistant and the role of the Curator agent. Pick "Get Started" to continue.
2 Choose Provider Connect and verify one or more AI providers (Anthropic, OpenAI, Google, Ollama, OpenRouter, etc.). You can add more later from Settings.
3 Choose Bootstrap Model Pick one already-configured model to bootstrap the Curator agent. The Curator will use it to recommend your long-term setup. A reliable frontier model (Claude Opus 4.x, GPT-5) is a good default.
4 Preference Questions Answer a few natural-language questions: speed vs. quality, privacy constraints, monthly budget, the kinds of tasks you run. Curator uses these to shape its recommendation.
5 Running Curator The Curator agent calls your bootstrap model, scans the 22-model catalog, and streams its reasoning live. Sit back and read along.
6 Review Recommendation Three exits: Accept — apply as-is; Edit — tweak the picks (detour: edit-recommendation); Redo with note — add a follow-up hint and re-run (detour: redo-input).
✓ Done The recommendation lands in HarnessSettings; the localFast, localDeep, and online slots are now bound.

Source of truth: src/ui/view/modals/harness-onboarding/state.ts defines the step order and the reducer.

3. Fonts & Appearance

If you take away one thing from this page, take this: Obsidian's default Interface and Text fonts (Inter) do not contain CJK glyphs. Chinese characters fall back per-glyph to the OS — usually PingFang on macOS — but the baseline and weight mismatch makes mixed-script text look thin and floaty.

The fix is to point Obsidian's three font stacks at the system font and add PingFang explicitly. One change, applies live, no restart.

Where to set it

Obsidian Settings → Appearance → Font. You will see three stacks. Configure all three.

Field Recommended stack
Interface font -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif
Text font -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif
Monospace font "SF Mono", "JetBrains Mono", Menlo, Consolas, "PingFang SC", monospace

Prefer to edit the file directly? Open this and change the corresponding keys:

<vault>/.obsidian/appearance.json

{
  "interfaceFontFamily": "-apple-system, BlinkMacSystemFont, \"PingFang SC\", \"Microsoft YaHei\", \"Segoe UI\", sans-serif",
  "textFontFamily":      "-apple-system, BlinkMacSystemFont, \"PingFang SC\", \"Microsoft YaHei\", \"Segoe UI\", sans-serif",
  "monospaceFontFamily": "\"SF Mono\", \"JetBrains Mono\", Menlo, Consolas, \"PingFang SC\", monospace"
}

Why we don't switch fonts by language tag

Per-glyph fallback is automatic.

CSS font-family fallback happens at the OS text layer (CoreText on macOS, DirectWrite on Windows). For every character, the OS walks the stack and uses the first font that has a glyph for it. Adding "PingFang SC" to the stack is enough — no :lang(zh) selector required.

This is how the big apps do it.

ChatGPT, Notion, and Linear all ship one system font stack. In a DevTools "Rendered Fonts" panel you can watch a single paragraph render Latin in SF Pro and CJK in PingFang UI, all from one font-family declaration.

Inside the plugin

Peak Assistant's design tokens already use a system stack with PingFang: 

/* src/styles/peak-tokens.css */
--pk-font-sans: -apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Segoe UI", sans-serif;
--pk-font-mono: "SF Mono", "JetBrains Mono", Menlo, Consolas, monospace;

Most plugin UI uses these tokens directly. A few containers inherit Obsidian's var(--font-interface) instead, which is why the Obsidian-level Appearance setting still matters for the parts of the plugin that live inside Obsidian's own chrome (sidebar, command palette, settings).

One-line summary. Add "PingFang SC" to the start of Obsidian's Interface, Text, and Monospace font stacks. The OS handles everything else.

5. Troubleshooting

Font change didn't apply

Most font changes apply live. If a specific view still shows Inter, close and reopen that tab. Reloading the plugin from the Community plugins settings also forces a refresh.

Curator recommendation failed

On the Review screen, click Redo with note and add a concrete hint such as "I write mostly Chinese notes, budget around $10 per month, privacy not critical." A short, specific note usually fixes a bad first run.

Want to reset Setup Wizard

Delete the existing provider bindings in Settings, then re-run Peak Assistant: Setup Wizard. The wizard will treat it as a first run.
