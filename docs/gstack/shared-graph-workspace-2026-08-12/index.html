Shared Graph Workspace

Graph 不是一个只负责“把节点画出来”的组件。对用户来说，它是一套稳定的关系工作空间：选择范围、切换投影、检查节点、保持视图、打开来源，并把关系带回当前写作上下文。

当前选择：World Search、File Atlas、AI Search Sources 与 Composer 应当共享同一个 Graph Workspace 外壳，只有宿主 capability manifest 不同。

多文件上下文决定图谱数据的边界，但不会自动授予多文件写入权限。选中节点以后，Composer 仍需要显式的 Add to context 或打开来源动作。

AI Graph 是持久化的、带来源和版本的关系产物；One hop 与 Two hop 则是当前上下文的即时 Vault 关系投影。两者可以共用视觉工作空间，但语义不能混在一起。
