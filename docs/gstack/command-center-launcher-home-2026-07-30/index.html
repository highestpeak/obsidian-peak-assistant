今天要推进什么？

把 Command Center 的产品边界确定下来：解决命令组织与返回工作的问题，不进入新的 dashboard widget 战场。

这块内容由 Obsidian 的 Note renderer 展示。Home 只负责布局和导航，不把正文复制进自己的配置。

当前笔记中的任务 核对现有 roadmap 完成竞品研究 评审 launcher 与 Home 原型
命令组与 Modal 共用一份配置

Excalidraw3 个精选动作
1

空 query 保留空间记忆

用户不是每次都想搜索。四个稳定分组比二十条动态排序结果更容易形成肌肉记忆。

2

搜索只筛选已策展内容

完整命令 catalog 只在管理态出现。日常搜索不会再次退化成原生 Palette 的无限全集。

3

Home 不再造数据系统

Todo、Base、Canvas 和文档都由原有 owner 渲染。Home 负责固定位置、导航和继续工作。

三条主路径

Modal、搜索和 Home 都回到明确目的地，不在 Command Center 内继续膨胀成工作台。

这次要做

  • 一个可绑定快捷键的 Peak Command Center 入口。
  • 二维命令组、真实快捷键、插件可用状态和用户短标题。
  • 同一配置驱动 Modal 与 Home。
  • 文件、Bookmark、Workspace 和现有 Vault 内容作为目的地。

这次不做

  • 不劫持或改写原生 Cmd+P。
  • 不复用旧 AI planner 作为启动器。
  • 不引入任意脚本、远程 widget 或 dashboard 市场。
  • 不使用 AI 生成 20px 功能图标；统一使用 Lucide。

这是设计原型，不是生产 UI 证据。正式实现仍需经过 focused tests、production build、Obsidian CDP 键盘与焦点验证，以及真实应用截图。
