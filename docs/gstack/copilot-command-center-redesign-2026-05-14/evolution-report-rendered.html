Conforming Baselines

基准 1：Search-like tab + Auto agent 入口。基准 2：Obsidian panel + quick action + review/apply。

Product Mapping

Document = Copilot，Vault = Vault Intelligence，Setting = Manage System。这是 UI 命名，不是再拆出一堆功能页。

Design Rule

视觉探索优先 imagegen 图；HTML 报告只负责组织、引用和说明，不再手写复杂原型当主方案。

Panel 状态机

Passive 打开 panel 后先展示 current context、推荐 2-3 个动作、最近运行和 pending review。
Planning 点击 Auto 或具体功能后，第一步永远是分析上下文和解释为什么要跑这些能力。
Running 每个功能显示自己的子步骤、数据源、scope、进度和可取消入口。
Reviewing 结果不直接写入。先给 candidates、reason、confidence、sources、preview 或 rendered diff。
Applied 应用后保留 undo、run log、引用来源，以及“继续下一步”的建议。

和 AI Analysis 一致的展示原则

用户需要看到 agent 正在想什么，但不要被 chain-of-thought 淹没。展示的是可产品化的分析摘要：输入信号、选择理由、运行步骤、结果证据、风险和下一步。

4. 功能触发后的 Step 展示

每个能力都有自己的小流程，但外层交互保持一致

Connect Links

适合从选中文本、当前段落或整篇 note 触发。

1
Analyze selection 识别关键概念、已有链接、语义意图和不该改写的文本。
2
Find candidates 结合 semantic search、backlinks、graph neighbors 和 tags 排序。
3
Preview links 展示候选、原因、置信度和插入位置，用户选择后 apply。

Add Evidence

适合文章、研究笔记和观点段落。

1
Detect claim 找出需要证据支撑的陈述、假设和薄弱段落。
2
Search sources 从 vault、引用笔记、相关文档里找可追溯来源。
3
Insert proposal 展示证据块、来源和插入预览；长改动进入 full diff。

Improve Note

适合 polish、结构调整和局部改写。

1
Assess risk 判断是轻量语气调整，还是可能改变事实/结构的高风险修改。
2
Draft changes 生成局部建议或文档级修改，并标明 rewrite rationale。
3
Rendered diff 红线/绿线展示删除和新增；用户选择 apply selected。

Vault Intelligence

Vault tab 的 Auto 不再让用户先选 Analyze / Synthesize / Maintain。

1
Resolve scope 判断当前 folder、project、topic、recent edits 或 entire vault。
2
Pick mode 自动选择分析、综合或维护，也可以组合成一个 run。
3
Produce queue 输出 digest、topic map、gap list、maintenance queue 或 saved plan。

Manage System

Setting tab 的 Auto 是系统诊断，不是知识工作流。

1
Check readiness 检查 index、providers、models、skills、prompts、usage 和错误日志。
2
Explain blockers 把不可用原因翻译成用户能处理的动作。
3
Fix or guide 能自动修的提出补丁；不能修的给设置入口和检查清单。

Manual Command

手动搜索是 fallback，不是默认首页。

1
Search command 支持输入 capability、note、folder、setting、recent run。
2
Configure run 必要时展示 scope、model、risk、output format。
3
Same review 即使手动触发，也走同一套 step、review、apply 和 undo。

从 tab 到 Auto，再到可审核结果
Open Peak Command

从侧栏、命令面板、选中文本、toolbar 打开同一个弹出入口。

Document Vault Setting
Choose Tab

Document 处理当前 note；Vault 处理知识库范围；Setting 处理系统状态。

Press Auto

Auto 是主按钮，不是“打开更多卡片”。它直接启动 agent planner。

Agent Plans

系统决定要跑 links、evidence、improve、tasks、synthesis、health 或 settings diagnostics。

Review / Apply

输出是 proposals、source cards、diff、digest 或 maintenance queue；用户审核后应用。

6. Tab 行为

三个 tab 的 Auto 都是 agent 自动编排，不是静态工具分类

Document / Copilot

Auto 会检查当前 note 或 selection：tags、links、evidence gaps、tasks、diagram opportunities、rewrite risk。结果进入右侧 panel 或 full diff。

Connect links Add evidence Improve note

Vault / Vault Intelligence

Auto 会先解析 scope，再选择 Analyze / Synthesize / Maintain。它可以生成 digest、source-backed report 或 maintenance queue。

Analyze Synthesize Maintain

Setting / Manage System

Auto 会诊断 index、models、providers、skills、prompts、usage 和配置健康。它不混进日常写作建议。

Index Models Skills

7. Review 规则

侧栏负责轻量审核；文档级修改必须进入 rendered diff

Current rendered note

小侧栏可以展示 link/tag/evidence 候选，但不适合承载全文改写。

- Removed block

The product can provide tags, links, summaries, and review comments from the side panel.

Proposed rendered note

全文或多段修改要在 rendered Markdown 上审核，不能只给 raw markdown。

+ Added block

Every document mutation is reviewed in a full rendered diff before apply, with provenance and undo.

8. 原始证据缩略图

这些是设计推导证据，不是当前视觉基准
当前报告刻意不再嵌入旧 HTML command-panel 原型，也不再把 full-page Command Center 图作为主视觉。它们可以作为历史资料存在，但当前 UX design 只围绕两张符合方向的 imagegen 基准图推进。
