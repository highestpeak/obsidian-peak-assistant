先把两种 Graph 分开

当前的 local / two-hop file graph 仍然有价值，但它不应该承担 AI Graph 的产品含义。

Neighborhood Graph

回答“这些文件怎么连”

  • 节点主要是 Vault 文件。
  • 关系来自 wikilink、semantic edge、folder path。
  • 确定性生成；切换 layout 不改变数据。
  • 默认只读，不产生独立 artifact。
AI Graph

回答“这些对象和观点是什么关系”

  • 节点可以是词汇、概念、实体、事件、主张、网页或文件。
  • 关系有 predicate、qualifier、证据、confidence 与 review 状态。
  • 每张图有稳定身份、不可变版本和来源历史。
  • AI Search、Composer、Search、Chat 重开同一张图。
产品裁决：允许两者共享 canvas renderer，但 domain model、生命周期和保存语义必须分离。

Revised IA · interactive

平级能力依赖：Shared AI Instruction Composer 是根级“共享产品能力”，与 AI Graph Artifact Platform 平级。Chat Studio、Composer Copilot、AI Graph 都是它的 consumers；AI Graph 只负责注入 graphId、baseVersion、selection、sources 与 review context，并把提交结果交给 semantic-diff runtime。
交互职责：Update graph 是自然语言修改入口，先给 semantic diff，接受后才创建新版本；Sources 只管理来源、freshness 与可用性，不代表图已经更新。
真实复用边界：Canvas、Topology / Thinking Tree / Bridges / Timeline、节点拖拽、平移、缩放、Controls 和 node click 全部来自生产 MultiLensGraph / @xyflow/react。原型壳为 Thinking Tree / Timeline 提供目标态 lens projection：树只接收父子主线，时间线只接收一份 evolution chain，避免生产当前的跨语义混线与 temporal 重复边。全屏查看、右侧 evidence / review、AI Search history 与 artifact persistence 是目标产品壳层。
证据不是装饰：没有 evidence 的 AI relation 默认进入 Needs review；AI 推断使用虚线，不能伪装成来源明确的事实。

同一张图可以容纳哪些对象

节点类型保持开放，关系语义保持受控。custom predicate 必须归入稳定 relation family。

Concept / term

词汇与概念

broader、narrower、related、defines、alias；不依赖任何文件才能存在。

Entity

真实世界对象

人物、组织、地点、产品、作品、数据集；同一对象可被多个来源提及。

Claim

观点与证据

supports、refutes、qualifies；冲突来源并存，不静默合成唯一真相。

Event / process

时间与因果

precedes、causes、enables、blocks、depends-on，并可带时间或范围 qualifier。

Vault document

本地来源

文件只是 node kind 之一；evidence 可定位 heading、block、line 与 exact quote。

Web resource

互联网来源

保存 canonical URL、capturedAt、content hash 与最小证据片段，不默认复制整页。

一份 artifact，多个入口

产品复用的关键不只是共享 renderer，而是共享 app-owned capability、repository 与 projection。

AI Search

AI Graph mode 复用紧凑 history list；analysis run 只保存 artifact ref。

Composer / File Atlas

当前文档或选区作为 context；显示 preview，可打开完整 Graph Detail。

Vault Search

Inspector 显示 Related Graphs 与 View all，不再只看最近 20 次 token overlap。

Chat Studio

Graph 作为可重开的 artifact card；conversation 保存 reference，不复制 graph body。

JSON artifacts

每张图拥有 stable graph ID、manifest 和 immutable version files。

SQLite projection

用于 AI Graph history、搜索、统计与 backlinks；删除后可从 artifact 重建。

实现前不可丢的设计红线

  • 不自动跑 Web：用户明确打开 Web，运行前看到 source scope 和成本级别。
  • snippet 不是证据：搜索摘要只找候选；relation 必须回到打开后的正文片段。
  • 不覆盖旧版本：source refresh 与 semantic edit 产生 immutable version。
  • 不让 UI store 充当数据库：selection、viewport、filter 可以 transient；graph truth 不可以。
  • 不复制 runtime：各 surface 只提供 context adapter 与呈现，不新建 graph agent / history。
  • 不默认写回 Vault：接受 relation 只改变 graph；写回笔记或 links 必须另行显式操作。
  • 不急着上 Neo4j / RDF：首版采用 versioned JSON property graph + SQLite projection。
