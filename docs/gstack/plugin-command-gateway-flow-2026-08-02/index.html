Command Gateway
不是 Command Center

这是 Copilot 调用第三方 Obsidian 插件 command 的安全桥。UI 只负责发现、解释和人工授权；真正执行发生在现有 Chat / Copilot Harness 中，而不是另造一个 launcher。

独立 worktree 源码已实现 未合入当前工作区 INTERACTION NOT VERIFIED

两个产品面，职责不同

Command Center人主动浏览、选择和启动 Peak 能力。它已经是独立的人机入口。
Command GatewayAgent 只能调用经过人工批准的第三方 plugin command，并留下权限与执行证据。

本 Mock 描绘 Gateway 本身的完整流程，不复用旧 Command Center launcher 稿，也不代表已经完成真实 Obsidian 验收。
