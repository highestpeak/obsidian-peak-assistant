## V2 设计方向

简单基准稿获得确认后，V2 将同一套规则带回完整工作台：

- 主记录 14.5px，普通字段 13.5px，辅助信息 12px；
- 默认数据行 42px；
- Stage Tag 24px 高、12px 字号、无边框；
- 普通单元格只保留 1px 横线，不再形成纵向笼子；
- 表头使用 2px 权威横线，字段类型图标默认隐藏；
- 数字、日期、金额和公式元数据使用等宽字体；
- 匹配度以明确数字为主体，不再常驻环形图；
- 进度条和等待条退到 2px 辅助线；
- 工作模式、普通优先级和空值使用文本，不强制套 Tag；
- 选区和活动单元格只使用 1.5px 紫色焦点；
- 工具栏、View、公式栏、紧凑搜索和筛选栏保留完整能力，但统一为轻量纸面层级。
- 文档头、视图栏、工具栏、公式栏和“已应用筛选”栏收敛到
  `52 / 38 / 38 / 32 / 28px` 的连续节奏；取消独立搜索横条，没有筛选时不保留空白栏位，并只使用单线分隔；
- 字段表头与列内容共享阅读轴：文本左对齐、数值右对齐、复选框居中。
- 公司与职位是两个独立文本字段，分别显示、选择和编辑；不再把职位藏在公司单元格的辅助文本里。
- 字段、筛选、排序和分组面板从各自按钮下方打开；打开面板只进入配置态，不会直接改变记录。
- 字段配置保留常驻左侧字段列表，可连续切换与逐项保存；保存不会关闭面板，“新增字段”会创建可命名、可选类型并实际进入表格的新列。
- 筛选支持 `全部 / 任一` 条件组合；排序支持多个优先级；分组支持最多三级。三者都能用自然语言生成一组仍可编辑的规则。
- 搜索作为约 218px 的紧凑输入进入主数据工具栏，记录数在输入框内反馈；视图栏不再保留重复的远端搜索入口。
- “重复项”使用正常工具栏命令；公司、职位、地点和 JD 链接进入独立面板，成为 32px 高、可切换的比较字段，而不是按钮下难以点击的小字。
- “自动格式”改为“显示格式 / 常规”，并移除本稿不需要的条件格式入口。
- 公式栏本身是智能入口：以 `=` 开头时直接编辑普通公式，输入中文业务规则时原地切换为 AI 模式，`Enter` 或栏内“生成候选”才打开候选比较面板；输入区限制在 680px 阅读宽度内，AI 状态与动作以 5px 间距紧跟输入框，不再漂到视口最右侧，28px 输入框在 32px 栏内保留完整焦点底边。顶部“AI 公式”仅用于快速聚焦，不是必经步骤。面板左侧仍可修改并重新生成，基础函数只作为次级手动入口。
- AI 分析抽屉改为编辑式摘要、证据行与后续问题，不再堆叠一组高圆角卡片。

## Motion 与编辑

- 交互反馈统一使用 `120 / 180 / 260ms`，不使用弹跳、漂浮或大幅位移；
- 视图切换使用 4px 淡入，浮层和对话框使用小幅位移与透明度过渡；
- 表格行 Hover 不改变底色，活动与编辑单元格只保留格内 1.5px 焦点线；
- 冻结列在选中和编辑时继续保持 Sticky，不使用外投影、溢出或提交闪光；
- `prefers-reduced-motion: reduce` 会把动画与过渡降到近乎即时；
- 普通单元格支持双击、`Enter` 或 `F2` 进入编辑；
- `Enter` 提交，`Tab / Shift+Tab` 提交并移动，`Esc` 取消；
- 提交与复选框切换只刷新受影响的单元格，不重建整表，并保持横向与纵向滚动位置；
- 文本、日期、数字、单选、复选框和链接使用匹配字段类型的编辑器；
- 公式与附件列保持只读，并在公式栏说明字段所有权；
- 编辑过程实时镜像到公式栏，提交后重新计算选区统计。

- 可组合、可排序优先级、可由 AI 起草的筛选、排序和分组规则；
- 单元格选区统计；

- AI ComputePlan、来源边界和移动预览；
- Paper / Graphite 主题切换。
