VAULT INTELLIGENCE · SCAN CONTRACT

从变化发现到用户决策：什么时候本地处理，什么时候 AI 参与，结果如何继续

一次 Scan 是一条有明确授权、模型、费用、停止语义和写入边界的知识库维护流程。Changed files 只负责触发；分析会叠加 affected context 和完整当前图。AI 可以动态规划和扩大证据，但不能越过 Setup 授权或预算。

本地确定性处理AI operation · 可计费用户授权或决定持久化与验证用户文件边界
一句话合同确定性系统建立事实，AI 在命名、语义、结构和维护判断中深入参与；用户在运行前控制授权与上限，在运行中控制每项 AI operation，在写入用户文件前进行最终批准。

3. AI operation 依赖图

不是单个巨大 Agent 调用。Coordinator 只在授权边界内编排；每项 operation 独立计费、独立停止、独立保存 receipt。

Local evidence foundationSearch、完整图、19 checks、旧决策、source revisions
AI scan planning决定真正需要分析的候选、顺序、证据深度
File understandingEmbeddings、Summary、AI Tags
Meaning & relationshipsRelationship discovery、semantic review
Structure judgmentCommunity → Hub/Bridge proposals
Optional file proposals只有证据充分且 Setup 允许时准备 diff
Maintenance synthesis事实、AI 判断、stops、partial results 合成用户结果
Completed + Work queue自动更新与用户后续明确分开
硬依赖：Community AI 必须有完整确定性图；proposal 必须有 finding 和 source revision。 软依赖：Community 可以在 AI Tags 不完整时继续，但必须标记 reduced evidence；Hub AI 被停止时，确定性 bridge 事实仍然有效。 预算规则：任何扩展、重试或 critique 都只能发生在 operation 自己的 scope/token/cost cap 内。

4. Progress 中停止 AI 时发生什么

用户撤回的是“剩余授权”，不是抹掉已经发生的调用，也不是停止所有本地维护。

QUEUEDSkip

operation 尚未发出任何 provider request。立即从剩余计划和费用预测移除。

结果：0 token、$0；依赖项按 hard/soft dependency 重新规划。
RUNNINGStop remaining

停止新请求并尝试取消 in-flight request。已经完成的文件或候选继续保留。

结果：provider 已处理部分可能仍计费；状态变成 partial/stopped。
COMPLETEDCannot disable retroactively

调用、token 和费用已经发生。用户只能在 Completed 决定 keep、discard、regenerate 或不 Apply。

结果：receipt 不可修改；机器知识是否发布由对应边界决定。
BUDGET CAPStop new AI calls

到达 hard cap 后不再开始新 AI request；本地 indexing、checks 与结果持久化继续。

结果：Completed 诚实标记 budget-stopped，不把整次 Scan 判失败。

6. 最终不能被界面隐藏的六条真相

这些是实现和验收时的底线，而不是可选文案。

Changed 不等于 isolated subset增量决定重算对象；完整当前图决定如何理解它们。
Estimated 不等于 actualSetup 给典型值和 cap；Progress 用 provider receipt 校正预测。
Unknown price 不等于 $0没有可靠价格时显示 Cost unavailable；本地模型显示 no metered API cost。
Stop 不等于 erase已完成结果和已发生费用保留；只撤回剩余 AI 授权。
AI proposal 不等于 graph/file truthCommunity 建议进入 versioned overlay；用户文件必须 explicit Apply。
Completed 可以包含 follow-up局部失败或用户决定不会抹掉已完成的 Search、结构和机器知识更新。
