删掉独立 Graph Library

AI Graph 的全量浏览就是 AI Search 中的 AI Graph 历史列表。持久化 artifact 仍然存在，但不再为它造第二套浏览产品。

只保留两个顶层位置

Vault Search 负责确定性找回；右侧 AI 工作区通过下拉在 AI Search、AI Graph 和 Vault Intelligence 之间切换。两侧保持原有等分布局并严格垂直居中。

每次普通打开回到 AI Search

低频模式不跨 modal 记忆。只有正在运行的 session、历史记录或 graph deep link 可以直接恢复对应模式。

模式只改变任务，不改变输入习惯

三种模式共享 PromptInput、Recent 列表与键盘规则；mode adapter 只改变 placeholder、建议、运行语义和历史 projection。
