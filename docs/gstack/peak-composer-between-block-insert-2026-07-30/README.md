# Peak Composer · 跟随指针的块间插入

Created: 2026-07-30

这是一个 focused、design-only 的交互 mock，用来评审 Composer 的通用块间插入入口。它不修改生产代码，也不表示该功能已经实现。

## 打开方式

直接在浏览器打开 [`index.html`](./index.html)。

## 设计结论

- 每两个可插入结构之间都有一条不可见的 insertion gap；空闲时不显示任何永久控件。
- 指针进入 gap 后显示一条轻量分隔线，圆形 `+` 的横向位置跟随指针，而不是固定贴左。
- 鼠标悬浮到 `+` 后立即冻结插入锚点并打开块类型菜单，不需要点击；菜单靠近边缘时自动向内收，箭头仍指向真实插入位置。
- `段落`是默认块类型；用户可直接按 Enter 创建并开始输入，也可切换到标题、列表、待办、引用、Callout、公式、图片、表格、Base、Canvas、Excalidraw 或 AI 续写。
- 入口属于“两个结构之间”，不属于上一个 Block。后续实现应让同一机制覆盖普通 Block、列表项和可容纳子结构的容器，但必须由语义插入边界决定是否出现。

## 交互预览

- 顶部 `静止 / 移动中 / 悬浮展开` 可切换三个状态。
- 在任意 gap 内横向移动鼠标，可以看到 `+` 跟随位置变化。
- 把鼠标停在 `+` 上就会打开菜单；从 `+` 移入菜单时保持展开，按 `Esc` 回到移动态。
