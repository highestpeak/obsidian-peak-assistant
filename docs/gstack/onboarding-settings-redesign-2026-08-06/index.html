先让用户成功，再让用户掌控。

这版不是给旧页面换皮。它把 Onboarding 重构成一次真实任务闭环，把 Settings 重构成系统状态与长期控制中心，并把 Provider、模型、Agent runtime 和媒体路由拆回正确层级。

Onboarding start

不再用三张泛化营销卡定稿；提供任务优先、工作区地图、真实文档起步三版供选择。

Settings depth

Model roles

关键产品决定

  • Onboarding 默认零偏好问题，系统先用已验证 capability 生成 Auto defaults。
  • Provider 的首发可见范围是 OpenAI、Anthropic、OpenRouter、Ollama、Codex、Claude Code。
  • Codex 与 Claude Code 作为 Agent runtime，不伪装成普通 chat provider。
  • 模型选择采用 6 个任务组、18 个 assignment；普通用户管理组默认，高级用户逐项覆盖。
  • Settings 不删除旧设置；Standard 分组降噪，Advanced 保留索引、路由、媒体、Agent、数据与诊断。
  • 模型选择器不是独立设置页，而是从任意具体 assignment 打开的共享 drawer。
  • 媒体能力回到核心产品叙事；高级 preset、route 与模板路径在 Advanced 中保留。
  • Onboarding 与 Settings 必须消费同一个 ReadinessProjection 和 verification receipt。
  • Setup 完成条件是目标 surface 真正打开且预填任务，而不是 modal 被关闭。
