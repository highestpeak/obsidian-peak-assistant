  • 不再常驻左侧栏 / ribbon；仅通过 Command Palette（Ctrl/Cmd + P）召唤
  • 命令名：Peak Assistant: Open Settings
  • 其他 modal 也同时暴露命令（Open Vault Search / Open Document Copilot / Run Vault Intelligence 等）

Rationale · 为什么这样切

  • 按"操作对象"分模态：Vault Search Modal 面向整个 vault；Document Copilot Modal 面向当前文档 / 光标上下文。语义单一，用户不会在同一个 modal 里被"vault-wide"和"cursor-local"两种心智反复切换。
  • Vault Intelligence 从 tab 降级为按钮：它是 30-60s + 高 token 成本的操作，不适合被 Tab 键"顺手扫过"。挪到右上角胶囊按钮，视觉上和两个 tab 隔离。
  • Atlas（原 Heading）从 Vault Search 迁到 Copilot：Atlas 本质是"读当前文档"的能力（快速跳转到 section / 结构总览），与 Copilot / Ambient 属于同一心智层。留在 Vault Search 会让 Vault Search 的心智从"整 vault 搜"稀释成"整 vault + 当前文档"。名字改为 Atlas 更贴合"结构地图"语义。
  • Settings 移出常驻：使用频率极低，占据入口位置得不偿失。Command palette 是 Obsidian 用户的肌肉记忆。
