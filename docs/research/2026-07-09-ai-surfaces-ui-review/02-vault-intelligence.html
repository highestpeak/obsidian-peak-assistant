Vault Intelligence Tab · UI/UX Review

Quick Search modal 内嵌的 Vault Intelligence 面板（vault 级 review 状态卡 + 历史 + suggested intents）全链路审阅。
读者：本插件维护者 证据：src/ui/view/copilot/ + src/service/copilot/vault/ 约 5,500 字 · 11 分钟 2026-07-09

综合判断

最大的问题不是视觉，是"半接线"：看起来完成度 90%，交互完成度约 50%

从 Quick Search modal 进入这个面板时，右栏三个 Suggested intents 和 "All reviews" 链接的 onClick 全部是空函数（SearchModal.tsx:903-906 的显式 stub）——用户点了没有任何反应。这比丑陋严重得多：它教育用户"这个插件的按钮不可信"。同一批组件从独立的 Copilot Modal 进入时是接好线的，坏的只是这个嵌入点。

第二类问题是把工程内部量原样倒给用户："143.7% word drift" 是个未封顶、无方向的百分比；"148 notes changed" 实际是文件数净差而非真实变更数；"cached report" 和 "can refresh" 是两个由同一个布尔量驱动的冗余调试标志。第三类是收尾粗糙：placeholder 是 Atlas tab 的字符串（正确的字符串已经算好了但没人用）、scope chip 显示原始小写 id "vault"、"Run strategy" 的问号没接 tooltip、"Research" 改名后周边文案还在说 "review"。

重设计 Mockup（After）

重画原则：指标翻译成用户语言，动作只留真实可点的，词族统一为 review 系。

✓ #1（接线，mockup 不可见）intents 与 All reviews 必须接到与 Copilot Modal 相同的 dispatch；接线前整栏隐藏。
✓ #2 placeholder 换成 intent-hub 里已经写好的 vault 串。
✓ #3 "143.7% word drift" → "words ≈2.4× (+1.0M)"：有方向、有量级、不装成一个封顶百分比。
✓ #4 "+148 notes" 诚实表达"净增 148 篇"；真实 changed 数待 per-file hash diff 落地后再展示。
✓ #5 "cached report"/"can refresh" 删除，信息合并进 "last report · 20 May 2026"。
✓ #6 词族统一 review 系：CTA "Run vault review"，footer "during a vault review"。
✓ #7 计数只显示非零项；全零显示 "No findings"。标题示例展示了"报告命名"应有的样子（≤60 字符判断句）。
✓ #8 问号删除，说明直接放为按钮上方一行小字（比藏在 tooltip 里更诚实）。
✓ #9 chip "vault" → "Vault"。
✓ #10 recommended 徽标只保留 Smart Connections 一枚（示例），语义是"真的过了 vault 级阈值"，而不是"每行都贴"。
✓ #11 日期统一 "20 May 2026"。

前后对比要点

  • 状态卡从"仪表盘碎片"变为"一句人话 + 三条事实 + 一个动作"。原版 6 个 meta chip 里有 3 个是工程状态（cached / can refresh / large delta），用户需要翻译；新版每个字都不需要翻译。
  • "recommended" 从装饰变回信号。三行全贴 recommended 时它的信息量是零；只有过阈值才贴，徽标才值得被看。
  • 词族统一是一次性决策，不是文案微调。Research/review/refresh 混用来自 2026-05-30 的单点改名没有跟着扫全 surface——建议这次把 MODE_LABELS 与周边 copy 一起定稿（本文与 03 篇 mockup 统一按 review 词族画）。
  • 死按钮是负资产。在接线完成之前，隐藏 Suggested intents 栏比展示三张点了没反应的卡片体验更好。

不做什么

  • 不动 review 运行链路（VaultAutoRunModal / VaultReviewSession 的运行与报告渲染不在本篇范围）。
  • 不合并 Vault Intelligence 与 AI Search 两个入口——分工清晰（问答 vs 体检），问题只在交付质量。
  • 不新增第四种 freshness 表达；A/B/C/D/E 五态状态机本身设计合理，坏的只是 D 态的文案层。
