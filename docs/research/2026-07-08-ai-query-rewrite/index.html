Design notes

Trigger 是显式的 · 不是每次输入都调 LLM。 用户必须手动点 ✦ AI。理由：token 成本、延迟、幽灵感。

每张卡片必须 grounding 在具体行为信号上。 LLM 的 reason 字段必须引用至少一个：user hovered X · switched to Y · recent query Z · active file 在某 folder 下。空话（如"this narrows results"）会被 prompt 判为低质。

3 秒缓存 + 手动 retry。 同一 context 3 秒内重复点 AI 返回同一批候选，超过 3 秒或 typed 新词则重算。避免用户误点浪费 tokens。

不做实时自动 rewrite / 不做多轮对话。 那是 AI Analysis / Vault Intelligence 的活。Query rewrite 定位是"当前搜索的加速器"，一次点击一次生成，用户是 pilot。

AI 按钮和 AI Analysis 语义冲突。 当前 AI 按钮 onClick 是跳到 AI Analysis tab。改成 rewrite 之后需要给 AI Analysis 另找入口。倾向：AI Analysis 保持独立 tab（顶部 tab 栏已经有），AI 按钮专职做 rewrite。
